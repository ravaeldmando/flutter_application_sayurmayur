# flutter_application_sayurmayur (PAM W6S2S3)

1. Ekstrak ke path sederhana, contoh: C:\flutter_apps\flutter_application_sayurmayur
2. Buka folder di VS Code, lalu di terminal (satu per satu):
   flutter create .
   flutter pub get
   flutter run
3. Ganti gambar di assets/ (box1..box6) dengan foto sayur asli (nama file sama, box3 = .jpeg).
